# Project Rules

## Prompt Log
- Log every prompt made in the IDE to `Prompt_Log.md`, including prompts that change nothing. Create the file if it doesn't exist.
- Each entry records the date/time, the prompt, what was changed and what changes were made. Follow the format in `Prompt_Log.md` and add new entries at the bottom.
- The log gets committed, so replace anything secret-like in a prompt with `[REDACTED]`.

## Git
- Before changing anything in the project, confirm the current branch is not `main`. If it is, create a branch first.
- Do not commit, push, merge or open pull requests. The user handles those.

## Project Rules
- Stack: React, HTML, CSS, JavaScript, Bootstrap.
- Maintain `README.md` so it shows how to install and maintain the app. Update it when something changes.
- Exclude unnecessary packages.
- Do not put API keys or other secret information in the code or in any file to be committed.
